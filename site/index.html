nocx

A local terminal that keeps your working context

Tabs, their output, notes and secret references survive a restart. Go backend, xterm.js on WebGL, one WebSocket. macOS and Linux.

Download for macOS universal .dmg · ad-hoc signed, not notarized Download for Linux x86_64 AppImage · glibc 2.35+ Source on GitHub MIT

v0.2.0 · released 2026-08-20 · early release, no formal support

macOS quarantines the download, because there is no Apple Developer ID and no notarization. Clearing it is one command, once — it is in Install, in full, before you download anything.
