The first release since v0.1.0, and the one where nocx stops forgetting things.
Close the app now and it opens where you left it: the same tabs, the output
those tabs printed, the window at the size you dragged it to. That is the
largest change, and the sidebar, the vault and the assistant arrived beside it.

## Your tabs come back, and so does what they printed

A restart used to cost you everything on screen. Now the tabs are restored, each
one still showing the blocks it had, and the tab that was in front is the tab
you land on. Turn it off in Settings under Interface if you would rather start
clean — the setting is `restore.onStartup`, and with it off a restart gives you
one fresh tab as before.

The window's own size and position are remembered too, along with the sidebar's
width and which panel you had open.

## Tabs group into workspaces

A workspace is a set of tabs with a name and a colour. Make one from the tab
strip's menu and it arrives with its first tab already open. Each workspace is a
pill in the strip: one click switches to it, and right-clicking the pill
renames, recolours or closes it. Closing asks first and tells you how many tabs
go with it, naming anything still running.

The workspace you start in draws no pill and never will. It has no name to
change and cannot be closed, so it shows no chrome you cannot use.

## Command history that survives the app

Commands you run are stored on disk and encrypted. Press Up at the prompt and
your history is there after a restart, not just within the session. The recall
panel searches it, and it tells you what it is searching — how far back the
store goes — rather than silently returning less than you expected.

You decide how much it keeps: retention in days, a disk ceiling, and a
per-command output cap all live in Settings under History. Recording output is a
separate switch from recording commands.

## Notes

Press ⌥⌘N on macOS, Alt+Super+N on Linux, and you are typing. The note opens as
a tab, saves itself as you pause, and is still there after a restart. The Notes
panel in the sidebar finds a note by any word inside it, not only by its title.
A note you open twice focuses the tab you already have rather than opening a
second one, and a note you never typed into is not left behind in the library.

## The command line itself

The prompt editor was rebuilt on CodeMirror. Shell syntax is highlighted as you
type, Tab completes commands and paths — directories complete with a trailing
slash and Tab again walks into them — and the top candidate appears as ghost
text that Right accepts. When nothing matches, the panel says so instead of
going blank.

Two keys that used to mean one thing now mean two: Enter takes the highlighted
completion and stops, leaving the command in the line where you can read it
before running it, and Tab, Right or End walk into it.

## The sidebar

Four panels, each about the machine the current tab is on.

**Files** shows the directory the tab is in and follows it: `cd` somewhere and
the tree moves, with no click and no tab switch. Clicking a file opens it in a
tab.

**Git** is the repository the tab is in — changed files with their line counts,
staging and unstaging, a commit form, and the log. It refuses what git refuses,
visibly, rather than failing quietly.

**Ports** lists the ports something in the tab is listening on and the tunnels
you have forwarded.

**Notes** is the note library described above.

## Secrets, and references instead of values

nocx has a vault. Type a key into the prompt and run it, and the block offers to
store it: the value goes into the vault and the command keeps a reference where
the secret was, so your history holds the reference and never the key. Recall
that command later and you get the reference back, rendered as a chip. Run it
and the vault asks you to unlock before substituting the real value — you never
have to go find a settings page first.

Connection passwords and key passphrases live there too, and you can import
existing connections from `~/.ssh/config` or a Tabby export.

## Snippets

Save a phrase once and fire it into whatever is taking input, including a
program in the middle of reading stdin. Multi-line bodies are refused when the
program has not enabled bracketed paste, rather than being pasted line by line
into something that cannot handle it.

## Asking about a command

Select the output of a finished command and a chip naming that command appears
in your input line, so you can see what you are about to send while you type the
question. The prompt has a switch beside it reading **Run**; click it, or press
Cmd+Enter (Ctrl+Enter on Linux), and the line goes to the assistant instead of
the shell.

The answer streams back as a block in the same scrollback, with your question as
its header. There is no chat pane and no separate mode to leave.

Configure an endpoint under Settings, Assistant, Endpoints before the first
question. With none configured the surfaces say so rather than failing when you
ask.

## Installing

**macOS**: the app is ad-hoc signed, not notarized, so the first launch needs
the manual quarantine step. **Linux**: `chmod +x` the AppImage.

Both are in the README.
