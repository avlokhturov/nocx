# Snippets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use beads-superpowers:subagent-driven-development (recommended) or beads-superpowers:executing-plans to implement this plan task-by-task. Each Task becomes a bead (`bd create -t task --parent <epic-id>`). Steps within tasks use checkbox (`- [ ]`) syntax for human readability.

**Goal:** A user saves a phrase once and puts it back into whatever is taking input — the command editor, a TUI running in the pane, or the clipboard — from a keystroke, with the parts that change filled in.

**Architecture:** A backend collection store (`internal/snippet`) behind `snippets.*` JSON-RPC methods with schemas in `contracts/`. In the renderer, a template resolver that substitutes live session values and asks the user for the rest **at fire time**, and a destination derivation that routes the resolved text through the existing `InputTargetRegistry`. Four entry points — palette, completion provider, toolbar menu, settings page — all read one store.

**Tech Stack:** Go 1.x (`storage.DocumentStore`, `internal/transport` JSON-RPC), TypeScript + SolidJS, CodeMirror 6, xterm.js, Vitest, Playwright.

**Spec:** `.internal/specs/2026-08-13-snippets-design.md` — read it before Task 1. Section references below (§N) point into it.

### Task 1: The `Snippet` type and its JSON store

**Files:**

- Create: `internal/snippet/snippet.go`
- Create: `internal/snippet/store.go`
- Test: `internal/snippet/store_test.go`

**Interfaces:**

- Consumes: `storage.DocumentStore` (`internal/storage/document.go`) — `Read(name string, into any) (found bool, err error)`, `Write(name string, doc any) error`.
- Produces:
  - `type Snippet struct { ID, Title, Body string }` with JSON tags `id`, `title`, `body`.
  - `type Store interface { LoadAll() ([]Snippet, error); SaveAll([]Snippet) error }`
  - `func NewJSONStore(docStore storage.DocumentStore, fileName string) *JSONStore`
  - `const DocumentName = "snippets.json"`

**Acceptance Criteria:**

- A store reading a document that does not exist returns an empty slice and no error — never `nil` with an error.
- A store round-trips a list and preserves its order exactly.
- A `Read` that fails propagates the error rather than reporting an empty library.
- `SaveAll` is safe under concurrent callers (mutex-guarded).

```go
package snippet

import (
	"fmt"
	"sync"

	"github.com/shady2k/nocx/internal/storage"
)

// DocumentName is the file the library lives in, under the app profile dir.
const DocumentName = "snippets.json"

// Store is the persistence seam. Whole-document read and write: the list is
// edited by hand, at human speed, and an incremental path would be complexity
// bought with nothing (design §5.1).
type Store interface {
	LoadAll() ([]Snippet, error)
	SaveAll(snippets []Snippet) error
}

// JSONStore persists the library as one JSON document:
//
//	{ "snippets": [...] }
type JSONStore struct {
	docStore storage.DocumentStore
	fileName string
	mu       sync.Mutex
}

func NewJSONStore(docStore storage.DocumentStore, fileName string) *JSONStore {
	return &JSONStore{docStore: docStore, fileName: fileName}
}

type storeData struct {
	Snippets []Snippet `json:"snippets"`
}

// LoadAll returns the stored list in order. A document that does not exist is
// an empty library, never an error; a read that FAILS is an error, never an
// empty library.
func (s *JSONStore) LoadAll() ([]Snippet, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	var d storeData
	found, err := s.docStore.Read(s.fileName, &d)
	if err != nil {
		return nil, fmt.Errorf("read snippet store: %w", err)
	}
	if !found {
		return []Snippet{}, nil
	}
	if d.Snippets == nil {
		return []Snippet{}, nil
	}
	return d.Snippets, nil
}

func (s *JSONStore) SaveAll(snippets []Snippet) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	if snippets == nil {
		snippets = []Snippet{}
	}
	if err := s.docStore.Write(s.fileName, storeData{Snippets: snippets}); err != nil {
		return fmt.Errorf("write snippet store: %w", err)
	}
	return nil
}
```

### Task 2: The service — id minting, permutation-checked reorder, seeding

**Files:**

- Create: `internal/snippet/service.go`
- Test: `internal/snippet/service_test.go`

**Interfaces:**

- Consumes: `Store`, `Snippet` from Task 1.
- Produces:
  - `func NewService(store Store) *Service`
  - `func (s *Service) List() ([]Snippet, error)`
  - `func (s *Service) Create(title, body string) (Snippet, error)` — **no id parameter**
  - `func (s *Service) Update(id, title, body string) (Snippet, error)`
  - `func (s *Service) Delete(id string) error`
  - `func (s *Service) Reorder(ids []string) ([]Snippet, error)`
  - `var ErrNotFound = errors.New("snippet not found")`
  - `var ErrNotAPermutation = errors.New("reorder ids are not a permutation of the stored list")`

**Acceptance Criteria:**

- `Create` mints the id; the caller cannot supply one (there is no parameter for it).
- Two `Create` calls never produce the same id.
- `Reorder` with a list that is missing an id, has an extra id, or has a duplicate is rejected with `ErrNotAPermutation` and **writes nothing**.
- `Update`/`Delete` on an unknown id return `ErrNotFound` and write nothing.
- Seeding happens when the document is **created**, not when it is empty: a library the user emptied stays empty across restarts.
- Every store error propagates.

`internal/snippet/service.go`:

```go
package snippet

import (
	"crypto/rand"
	"encoding/hex"
	"errors"
	"fmt"
	"sync"
)

var (
	ErrNotFound        = errors.New("snippet not found")
	ErrNotAPermutation = errors.New("reorder ids are not a permutation of the stored list")
)

// seeds are two ordinary records written when the document is first created.
// They are not built-ins: no override layer, no restore, no reset. Their only
// job is to teach the placeholder syntax at the moment the library would
// otherwise be empty (design §5.3).
func seeds() []Snippet {
	return []Snippet{
		{
			ID:    newID(),
			Title: "Explain this branch",
			Body:  "Explain what changed in {{env:branch}} under {{env:cwd}}.",
		},
		{
			ID:    newID(),
			Title: "Forward a port",
			Body:  "ssh -L {{ask:local=8080}}:localhost:{{ask:remote=8080}} {{env:host}}",
		},
	}
}

func newID() string {
	var b [16]byte
	if _, err := rand.Read(b[:]); err != nil {
		panic(fmt.Sprintf("snippet: crypto/rand failed: %v", err))
	}
	return hex.EncodeToString(b[:])
}

// Service owns the policy over the store: ids are minted here, a reorder must
// be a permutation, and seeding happens exactly once.
type Service struct {
	store Store
	mu    sync.Mutex
}

func NewService(store Store) *Service {
	return &Service{store: store}
}

// ensureSeeded writes the seed records if the document has never existed.
// Caller must hold s.mu.
func (s *Service) ensureSeededLocked() error {
	exists, err := s.store.Exists()
	if err != nil {
		return err
	}
	if exists {
		return nil
	}
	return s.store.SaveAll(seeds())
}

func (s *Service) List() ([]Snippet, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	if err := s.ensureSeededLocked(); err != nil {
		return nil, err
	}
	return s.store.LoadAll()
}

func (s *Service) Create(title, body string) (Snippet, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	if err := s.ensureSeededLocked(); err != nil {
		return Snippet{}, err
	}
	list, err := s.store.LoadAll()
	if err != nil {
		return Snippet{}, err
	}
	created := Snippet{ID: newID(), Title: title, Body: body}
	if err := s.store.SaveAll(append(list, created)); err != nil {
		return Snippet{}, err
	}
	return created, nil
}

func (s *Service) Update(id, title, body string) (Snippet, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	list, err := s.store.LoadAll()
	if err != nil {
		return Snippet{}, err
	}
	for i := range list {
		if list[i].ID != id {
			continue
		}
		list[i].Title = title
		list[i].Body = body
		if err := s.store.SaveAll(list); err != nil {
			return Snippet{}, err
		}
		return list[i], nil
	}
	return Snippet{}, ErrNotFound
}

func (s *Service) Delete(id string) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	list, err := s.store.LoadAll()
	if err != nil {
		return err
	}
	out := make([]Snippet, 0, len(list))
	found := false
	for _, sn := range list {
		if sn.ID == id {
			found = true
			continue
		}
		out = append(out, sn)
	}
	if !found {
		return ErrNotFound
	}
	return s.store.SaveAll(out)
}

// Reorder takes the FULL id list and rejects anything that is not a
// permutation of what is stored. A partial reorder is how two clients
// silently drop a record; the check runs before any write, so a rejected
// reorder leaves the document exactly as it was.
func (s *Service) Reorder(ids []string) ([]Snippet, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	list, err := s.store.LoadAll()
	if err != nil {
		return nil, err
	}
	if len(ids) != len(list) {
		return nil, ErrNotAPermutation
	}
	byID := make(map[string]Snippet, len(list))
	for _, sn := range list {
		byID[sn.ID] = sn
	}
	out := make([]Snippet, 0, len(ids))
	seen := make(map[string]struct{}, len(ids))
	for _, id := range ids {
		sn, ok := byID[id]
		if !ok {
			return nil, ErrNotAPermutation
		}
		if _, dup := seen[id]; dup {
			return nil, ErrNotAPermutation
		}
		seen[id] = struct{}{}
		out = append(out, sn)
	}
	if err := s.store.SaveAll(out); err != nil {
		return nil, err
	}
	return out, nil
}
```

```go
import (
	"context"

	"github.com/shady2k/nocx/internal/transport/control"

type snippetHandlers struct {
	svc *snippet.Service // nil → not wired
	r   Responder
}

func snippetErrorCode(err error) int {
	switch {
	case errors.Is(err, snippet.ErrNotFound):
		return -32602
	case errors.Is(err, snippet.ErrNotAPermutation):
		return -32602
	default:
		return -32603
	}
}

// listResult is the wire shape for list and reorder. The slice is
// initialised, never nil: `snippets` must marshal as [] on an empty library.
type snippetListResult struct {
	Snippets []snippet.Snippet `json:"snippets"`
}

func wireList(list []snippet.Snippet) snippetListResult {
	if list == nil {
		list = []snippet.Snippet{}
	}
	return snippetListResult{Snippets: list}
}

func (h snippetHandlers) handleMethod(_ context.Context, req jsonrpcRequest) {
	if h.svc == nil {
		_ = h.r.TryError(req.ID, RPCError{Code: -32601, Message: "snippets not available"})
		return
	}
	switch req.Method {
	case "snippets.list":
		list, err := h.svc.List()
		if err != nil {
			_ = h.r.TryError(req.ID, RPCError{Code: snippetErrorCode(err), Message: err.Error()})
			return
		}
		_ = h.r.TryResult(req.ID, mustMarshal(wireList(list)))

	case "snippets.create":
		// Deliberately no ID field: there is no call shape in which the
		// renderer could mint an id (design §5.1).
		var params struct {
			Title string `json:"title"`
			Body  string `json:"body"`
		}
		if err := json.Unmarshal(req.Params, &params); err != nil {
			_ = h.r.TryError(req.ID, RPCError{Code: -32602, Message: "Invalid params"})
			return
		}
		created, err := h.svc.Create(params.Title, params.Body)
		if err != nil {
			_ = h.r.TryError(req.ID, RPCError{Code: snippetErrorCode(err), Message: err.Error()})
			return
		}
		_ = h.r.TryResult(req.ID, mustMarshal(created))

	case "snippets.update":
		var params struct {
			ID    string `json:"id"`
			Title string `json:"title"`
			Body  string `json:"body"`
		}
		if err := json.Unmarshal(req.Params, &params); err != nil || params.ID == "" {
			_ = h.r.TryError(req.ID, RPCError{Code: -32602, Message: "Invalid params"})
			return
		}
		updated, err := h.svc.Update(params.ID, params.Title, params.Body)
		if err != nil {
			_ = h.r.TryError(req.ID, RPCError{Code: snippetErrorCode(err), Message: err.Error()})
			return
		}
		_ = h.r.TryResult(req.ID, mustMarshal(updated))

	case "snippets.delete":
		var params struct {
			ID string `json:"id"`
		}
		if err := json.Unmarshal(req.Params, &params); err != nil || params.ID == "" {
			_ = h.r.TryError(req.ID, RPCError{Code: -32602, Message: "Invalid params"})
			return
		}
		if err := h.svc.Delete(params.ID); err != nil {
			_ = h.r.TryError(req.ID, RPCError{Code: snippetErrorCode(err), Message: err.Error()})
			return
		}
		_ = h.r.TryResult(req.ID, mustMarshal(struct {
			ID string `json:"id"`
		}{ID: params.ID}))

	case "snippets.reorder":
		var params struct {
			IDs []string `json:"ids"`
		}
		if err := json.Unmarshal(req.Params, &params); err != nil {
			_ = h.r.TryError(req.ID, RPCError{Code: -32602, Message: "Invalid params"})
			return
		}
		list, err := h.svc.Reorder(params.IDs)
		if err != nil {
			_ = h.r.TryError(req.ID, RPCError{Code: snippetErrorCode(err), Message: err.Error()})
			return
		}
		_ = h.r.TryResult(req.ID, mustMarshal(wireList(list)))
	}
}

	}

		regResponder(sub, "snippets.list", build),
		regResponder(sub, "snippets.create", build),
		regResponder(sub, "snippets.update", build),
		regResponder(sub, "snippets.delete", build),
		regResponder(sub, "snippets.reorder", build),
	}
}
```

```ts
// namespace, so a third feature cannot claim one twice.
//
// Deliberately NOT a shared scan. `env` and `ask` spans are resolved before
// the text reaches any destination, so no document secret-reference.ts scans
// ever contains one — a shared parser would buy nothing at runtime while
// placing the vault's resolution path in this feature's change budget. What
// is genuinely one concept is who OWNS a namespace, and that is what lives
// here. Design §7.2.
export const REFERENCE_NAMESPACES = {
  secret: 'vault (secret-reference.ts / vault.resolveLine)',
  env: 'snippets (resolved at fire time)',
  ask: 'snippets (resolved at fire time)',
```

`frontend/src/snippets/reference.ts`:

```ts
// The snippets half of the {{ns:arg}} grammar: env and ask, never secret.
// The grammar rules are inherited from the vault's scan because they were
// bought there — the arg is open (spaces are legal), only `}` is structural,
// and a malformed span matches nothing.
export { REFERENCE_NAMESPACES, type ReferenceNamespace } from './reference-namespaces'

/** The namespaces THIS scan owns. A closed alternation, so an unknown
 *  namespace matches nothing anywhere and stays visible as literal text. */
export const SNIPPET_REFERENCE_RE = /\{\{(env|ask):([^}]*)\}\}/g

export interface SnippetSpan {
  from: number
  to: number
  ns: 'env' | 'ask'
  arg: string
}

/** Every well-formed env/ask span in `input`, in first-occurrence order.
 *  Offsets are UTF-16 code-unit positions — what CM6 uses. */
export function findSnippetSpans(input: string): SnippetSpan[] {
  const out: SnippetSpan[] = []
  for (const m of input.matchAll(SNIPPET_REFERENCE_RE)) {
    out.push({
      from: m.index,
      to: m.index + m[0].length,
```

```ts
// Resolution happens at fire time, once, whatever the destination. CM6 ships
// snippet tab-stops and they were tempting for `ask:` in the editor with a
// form elsewhere — rejected, because that is two implementations of "fill in
// the blanks" that would agree in every case anyone tried. Design §8.
import { findReferences } from '../secret-reference'
import { findSnippetSpans } from './reference'

/** The live facts an `env:` key may read. `null` means "cannot be answered
 *  right now" — never "empty". */
export interface SessionFacts {
  cwd: string | null
  host: string | null
  user: string | null
  branch: string | null
}

export interface AskField {
  readonly name: string
  readonly defaultValue: string
}

export type ResolveOutcome =
  | { kind: 'resolved'; text: string }
  | { kind: 'needs-fields'; fields: AskField[] }
  | { kind: 'refused'; reason: 'env-unavailable'; keys: string[] }

/** `port=8080` → name `port`, default `8080`. `port` → default ''. Only the
 *  FIRST `=` separates, so a default may contain one. */
function splitAsk(arg: string): AskField {
  const at = arg.indexOf('=')
  if (at < 0) return { name: arg, defaultValue: '' }
  return { name: arg.slice(0, at), defaultValue: arg.slice(at + 1) }
}

/** The distinct fields a body asks for, in first-occurrence order. One entry
 *  per NAME: the same name twice is one question and two substitutions. */
export function askFields(body: string): AskField[] {
  const out: AskField[] = []
  const seen = new Set<string>()
  for (const span of findSnippetSpans(body)) {
    if (span.ns !== 'ask') continue
    const field = splitAsk(span.arg)
    if (seen.has(field.name)) continue
    seen.add(field.name)
    out.push(field)
  }
  return out
}

/** True when the text carries a vault reference. Read-only use of the vault's
 *  own scan — this module never resolves one. */
export function hasSecretReference(text: string): boolean {
  return findReferences(text).length > 0
}

function envValue(key: string, facts: SessionFacts): string | null {
  switch (key) {
    case 'cwd':
      return facts.cwd
    case 'host':
      return facts.host
    case 'user':
      return facts.user
    case 'branch':
      return facts.branch
    default:
      return null
  }
}

export function resolveBody(
  body: string,
  facts: SessionFacts,
  answers: ReadonlyMap<string, string>,
): ResolveOutcome {
  const spans = findSnippetSpans(body)
  if (spans.length === 0) return { kind: 'resolved', text: body }

  const pending = askFields(body).filter((f) => !answers.has(f.name))
  if (pending.length > 0) return { kind: 'needs-fields', fields: pending }

  // Collect every unavailable env key BEFORE substituting anything, so the
  // refusal names all of them and nothing partial is ever produced.
  const missing: string[] = []
  for (const span of spans) {
    if (span.ns !== 'env') continue
    if (envValue(span.arg, facts) === null) missing.push(span.arg)
  }
  if (missing.length > 0) return { kind: 'refused', reason: 'env-unavailable', keys: missing }

  // Substitute right-to-left so earlier offsets stay valid.
  let text = body
  for (let i = spans.length - 1; i >= 0; i--) {
    const span = spans[i]
    const value =
      span.ns === 'env'
        ? (envValue(span.arg, facts) ?? '')
        : (answers.get(splitAsk(span.arg).name) ?? '')
    text = text.slice(0, span.from) + value + text.slice(span.to)
  }
  return { kind: 'resolved', text }
}
```

```ts
// The one list every surface reads. There is no change notification on the
// wire (design §6): one window, one client, and every writer is a surface
// inside it — so a mutation re-reads rather than being pushed.
import type { SnippetsList } from '../generated/snippets.list'

export type Snippet = SnippetsList['snippets'][number]

/** The subset of SnippetsClient the store needs — declared so tests can
 *  substitute a fake without a WebSocket. */
export interface SnippetsClientLike {
  list(): Promise<{ snippets: Snippet[] }>
  create(title: string, body: string): Promise<Snippet>
  update(id: string, title: string, body: string): Promise<Snippet>
  remove(id: string): Promise<{ id: string }>
  reorder(ids: string[]): Promise<{ snippets: Snippet[] }>
}

export type SnippetsState =
  | { kind: 'loading' }
  | { kind: 'ready'; snippets: readonly Snippet[] }
  | { kind: 'unavailable'; message: string }

export class SnippetsStore {
  private current: SnippetsState = { kind: 'loading' }
  private subscribers = new Set<(s: SnippetsState) => void>()

  constructor(private readonly client: SnippetsClientLike) {}

  state(): SnippetsState {
    return this.current
  }

  subscribe(cb: (s: SnippetsState) => void): () => void {
    this.subscribers.add(cb)
    cb(this.current)
    return () => this.subscribers.delete(cb)
  }

  private set(next: SnippetsState): void {
    this.current = next
    for (const cb of this.subscribers) cb(next)
  }

  /** Re-read the library. A failure is `unavailable` with the reason — never
   *  `ready` with an empty list, which would tell the user they have no
   *  snippets when in fact we could not look (design §11.5). */
  async refresh(): Promise<void> {
    try {
      const res = await this.client.list()
      this.set({ kind: 'ready', snippets: res.snippets })
    } catch (err) {
      this.set({ kind: 'unavailable', message: err instanceof Error ? err.message : String(err) })
    }
  }

  async create(title: string, body: string): Promise<void> {
    await this.client.create(title, body)
    await this.refresh()
  }

  async update(id: string, title: string, body: string): Promise<void> {
    await this.client.update(id, title, body)
    await this.refresh()
  }

  async remove(id: string): Promise<void> {
    await this.client.remove(id)
    await this.refresh()
  }

  async reorder(ids: string[]): Promise<void> {
    await this.client.reorder(ids)
    await this.refresh()
  }
}
```

```ts
// Design §9.
import type { InputTarget } from '../input-target'
import { findReferences } from '../secret-reference'

export interface FireEnvironment {
  /** Is the command editor showing? While a program owns the pane it is
   *  hidden — it has yielded its box to the live region. */
  editorShowing: boolean
  /** The registry's active target. */
  activeTarget: InputTarget
  /** Paste into the active pane through the terminal engine, which owns
   *  bracketed-paste wrapping. */
  pasteToPane(text: string): void
  /** Has the running program enabled mode 2004? */
  bracketedPasteActive(): boolean
  copyToClipboard(text: string): Promise<void>
}

export type FireOutcome =
  | { kind: 'delivered'; to: 'editor' | 'pane' | 'clipboard' }
  | {
      kind: 'refused'
      reason: 'secret-reference' | 'multiline-without-bracketed-paste'
      detail: string
    }

function secretRefusal(text: string): FireOutcome | null {
  const refs = findReferences(text)
  if (refs.length === 0) return null
  return {
    kind: 'refused',
    reason: 'secret-reference',
    detail: refs.map((r) => r.name).join(', '),
  }
}

export async function fire(
  text: string,
  env: FireEnvironment,
  opts: { toClipboard: boolean },
): Promise<FireOutcome> {
  if (opts.toClipboard) {
    const refused = secretRefusal(text)
    if (refused) return refused
    await env.copyToClipboard(text)
    return { kind: 'delivered', to: 'clipboard' }
  }

  // The ONE place that reads whether a target can insert, and it reads it to
  // choose — a destination that cannot insert is never offered, so it is
  // never refused at click time.
  if (env.editorShowing && env.activeTarget.insert) {
    await env.activeTarget.insert(text)
    return { kind: 'delivered', to: 'editor' }
  }

  const refused = secretRefusal(text)
  if (refused) return refused

  if (text.includes('\n') && !env.bracketedPasteActive()) {
    return {
      kind: 'refused',
      reason: 'multiline-without-bracketed-paste',
      detail: 'the running program would read the first newline as Return',
    }
  }

  env.pasteToPane(text)
  return { kind: 'delivered', to: 'pane' }
}
```

```ts
type PaletteView =
  | { kind: 'list' }
  | { kind: 'fields'; snippet: Snippet; fields: AskField[] }
  | { kind: 'refused'; message: string }

async accept(opts: { toClipboard: boolean }): Promise<void> {
  const snippet = this.selected()
  if (!snippet) return
  const answers = this.view.kind === 'fields' ? this.collectAnswers() : new Map<string, string>()
  const outcome = resolveBody(snippet.body, this.deps.facts(), answers)
  if (outcome.kind === 'needs-fields') {
    this.view = { kind: 'fields', snippet, fields: outcome.fields }
    this.render()
    return
  }
  if (outcome.kind === 'refused') {
    this.view = { kind: 'refused', message: `Cannot fill ${outcome.keys.join(', ')} here.` }
    this.render()
    return
  }
  const fired = await this.deps.fire(outcome.text, this.deps.environment(), opts)
  if (fired.kind === 'refused') {
    this.view = { kind: 'refused', message: refusalMessage(fired) }
    this.render()
    return
  }
  this.close()
  this.deps.returnFocus()
}
```

```ts
import { test, expect } from '@playwright/test'
import { openApp, gridText, rowCount } from './helpers' // use the helpers the suite already has

test('a snippet reaches a running program filled in, and is not submitted', async ({ page }) => {
  const app = await openApp(page)

  // 1 — create the snippet through the settings page, as a user does.
  await app.openSettings('snippets')
  await page.getByRole('button', { name: /new snippet/i }).click()
  await page.getByLabel('Title').fill('Ask about the tree')
  await page.getByLabel('Body').fill('look at {{env:cwd}} on port {{ask:port=8080}}')
  await page.getByRole('button', { name: /save/i }).click()
  await app.closeSettings()

  // 2 — a long-running program owns the pane. `cat` is present in every
  // image, never exits on its own, and the tty's own ECHO puts pasted text on
  // the grid WITHOUT a newline — which is what steps 5 and 6 need to tell
  // "inserted" from "submitted" apart.
  await app.type('cat\n')
  await expect.poll(() => app.paneMode()).toBe('running') // state, not a duration
  const rowsBefore = await rowCount(page)

  // 3 — the palette, while the terminal has focus and no editor exists.
  await page.keyboard.press('Alt+Meta+p')
  await expect(page.getByRole('listbox', { name: /snippets/i })).toBeVisible()
  await page.getByRole('option', { name: 'Ask about the tree' }).click()

  // 4 — the field form, in place, with the default prefilled.
  const port = page.getByRole('textbox', { name: 'port' })
  await expect(port).toHaveValue('8080')
  await port.fill('9000')
  await page.keyboard.press('Enter')

  // 5 — the resolved text is on the grid.
  const cwd = await app.sessionCwd()
  await expect.poll(() => gridText(page)).toContain(`look at ${cwd} on port 9000`)

  // 6 — and nothing was submitted.
  expect(await rowCount(page)).toBe(rowsBefore)
})

test('a multi-line snippet is refused when the program has bracketed paste off', async ({
  page,
}) => {
  const app = await openApp(page)
  await app.createSnippet('Two lines', 'first line\nsecond line')
  await app.type('cat\n') // cat does not enable mode 2004
  await expect.poll(() => app.paneMode()).toBe('running')
  await page.keyboard.press('Alt+Meta+p')
  await page.getByRole('option', { name: 'Two lines' }).click()
  await expect(page.getByText(/newline as Return/i)).toBeVisible()
  expect(await gridText(page)).not.toContain('first line')
})

test('a snippet carrying a vault reference is refused at a pane', async ({ page }) => {
  const app = await openApp(page)
  await app.createSnippet('With a secret', 'psql {{secret:prod-db}}')
  await app.type('cat\n')
  await expect.poll(() => app.paneMode()).toBe('running')
  await page.keyboard.press('Alt+Meta+p')
  await page.getByRole('option', { name: 'With a secret' }).click()
  await expect(page.getByText(/prod-db/)).toBeVisible()
  expect(await gridText(page)).not.toContain('psql')
})
```
