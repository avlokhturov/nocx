## What shipped

**Workspaces are done.** Six children of `nocx-isoph`, all merged and closed:
the store, the wire, the container lifecycle, the renderer handover, the chip,
and the close dialog. Verified end to end in both browsers against the real
backend:

```
✓ a workspace is a group of tabs, and the window shows one at a time
  › created with its first tab, switched between, and closed
    — while the default never renders
✓ a decorated strip survives the renderer
  › colour, name, pinning and order all come back after a reload
```

The epic stays OPEN because `nocx-isoph.7` is open under it: a vertical strip
cannot create a workspace (the chip is horizontal-only by design and the
per-group affordances were never built), and `workspaces.rename`/`reorder`
answer on the wire with nothing calling them.

**The tree calls a pane a pane** (`nocx-ehkvy`). `tab` now means only the strip
entry. `/home/dev/.herdr/briefs/check-pane-sweep.sh` is the acceptance: it must
print nothing.

**The ledger is reachable**, both ways. `ledger.open/bind/close` write,
`ledger.query/get` read, the redaction receipt survives, an entry can name its
host, and the query answers the recall search box.

**The foundation slice** — session identity, an unforgeable lineage edge,
liveness with `unknown` as a first-class answer, and a non-null `workspaceId`
that is now DERIVED from pane → tab → workspace.

## Non-obvious things that will cost you a session if you rediscover them

**`deadcode -filter <pkg>` cannot fail on `internal/content`.** RTA marks every
method reached through an interface as reflection-reachable, so the filter form
has always printed nothing there regardless of whether the write path had a
caller — and that is the exact package where a dead write path once shipped. Ask
`deadcode -tags gtk3 -whylive <pkg>.<Type>.<Method>` instead, and read the
contrast between a wired symbol and an unwired one. The ratchet shares the blind
spot: a dead METHOD behind a live interface is invisible to it. AGENTS.md now
says all of this.

**Every Go command on this host needs `-tags gtk3` and `CGO_ENABLED=1`.** Wails
v3 defaults to GTK4/webkitgtk-6.0, which is absent; without the tag cgo fails
before reaching our code.

**Five `internal/app` tests fail here and pass in CI** with `fork/exec
/bin/bash: no such file or directory` — NixOS has no `/bin/bash`. Plus one
live-sshd timeout. `nocx-58gq`, `nocx-65v6`. Do not chase them.

**`nocx-1wwm` is a real containerized flake** — `TestLiveSshd_SSHChildAssembly_
ChildEstablishesOverComposedLine`, roughly one run in two. Seen 2026-08-18 under
a merge that changed no Go at all, green on immediate re-run.

**The e2e suite keeps ONE home for the whole run** (`nocx-9jcx7`). Any spec that
writes a named record hands it to the next reader of that list; the two
surviving `notes` failures are that and nothing else. The LAYOUT reset in
`e2e/harness.ts` handles tabs and panes and runs BEFORE each test — a teardown
answers for the test that has just died and is skipped exactly when it matters.

**`.beads/issues.jsonl` is a generated export.** It blocks `git checkout` and
`git merge` when staged. `git reset -q HEAD -- .beads/issues.jsonl && git
checkout -- .beads/issues.jsonl` before switching branches. Never resolve it by
hand.
